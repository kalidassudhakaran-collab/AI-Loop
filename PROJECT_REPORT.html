1. Overview

LOOP is a multi-tenant Voice-of-Customer web application that turns scattered customer feedback (support tickets, reviews, surveys, sales notes, CSV uploads) into themes, sentiment trends, grounded Q&A, and leadership-ready digests.

Headline: LOOP turns scattered customer feedback into a ranked, evidence-backed list of what to do next.

Problem

Teams struggle to triage unstructured feedback across channels. Manual tagging is slow and leadership reports are hard to keep evidence-based.

Solution

  • Secure workspace-scoped ingest and storage
  • AI-assisted classification and Ask LOOP answers with citations (no invented quotes)
  • RBAC: Admin / Analyst / Viewer
  • VoC reports from pre-computed stats + AI narrative; shareable and printable

3. Architecture & Screenshots

Architecture

Browser (App Router UI)
    │  session cookie only — never trusted client workspaceId
    ▼
Next.js Route Handlers (auth + RBAC + Zod)
    ├── Prisma → PostgreSQL (+ pgvector)
    ├── Claude / Gemini (server-only API keys)
    └── Embeddings → vector(768) retrieval for Ask LOOP

Business logic lives in lib/services/*. UI never talks to the database or AI providers directly. Ask LOOP: question → embed → retrieve → evidence → optional LLM answer with validated citations.
